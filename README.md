# python-pptx-tools
Some scripts using the super `/scanny/python-pptx` library that I've created to help me build image based animations using powerpoint. I doubt whether anybody will find these useful. If you do, however, then you're very welcome!

- door-animate.py: Create a new pptx file with an animation a given door image swinging inwards.
- editor-poc.py: An example of how to dig "under the covers" of `python-pptx`
- extract-images.py: Extract selected images from a pptx file. 
- tidy-images.py: Delete working images from the project folder that are already in the pptx file.
